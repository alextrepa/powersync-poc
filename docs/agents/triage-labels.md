# Triage labels

The engineering skills use five canonical triage roles. This repository uses the default role names as its local Markdown status values.

| Canonical role | Repository status | Meaning |
|---|---|---|
| `needs-triage` | `needs-triage` | A maintainer must evaluate the issue. |
| `needs-info` | `needs-info` | Work is waiting for more information from the reporter. |
| `ready-for-agent` | `ready-for-agent` | The issue is specified and ready for an autonomous agent. |
| `ready-for-human` | `ready-for-human` | The issue requires human implementation. |
| `wontfix` | `wontfix` | The issue will not be actioned. |

When a skill names a canonical role, use the corresponding repository status from this table.
